# DATLUME Google AdSense / 収益化設計

最終更新: 2026-09-27
ステータス: AdSenseサイト審査申請済み・審査待ち

## 1. 目的
Cloudflare等の運用費と将来の拡張費をサイト収益で補えるよう、Google AdSenseを初期収益化手段として導入する。
収益最大化より先に、データサイトとしての信頼性・可読性・表示速度を維持する。

## 2. 現在の実装
- Publisher ID: `pub-7677179691441346`
- `/ads.txt` にGoogleのDIRECT行を配置済み。
- トップページに `google-adsense-account` 所有権確認metaを配置済み。
- `/privacy/` を公開し、AdSense、Cookie、アクセス解析、CMP等を説明。
- 主要ページのfooterからプライバシーポリシーへ到達可能。
- HTML監査で上記が消えていないことを回帰確認する。

## 3. 審査中の方針
AdSense審査完了までは、広告表示用スクリプトを全ページへ機械的に入れない。
所有権確認・ads.txt・privacy・コンテンツ品質の状態を維持する。
審査結果が出るまで、広告コードの試行錯誤でUXやページ速度を変化させない。

## 4. 審査通過後の初期配置方針
最初は広告密度を低くする。
候補:
- 記事/データ本文の区切り位置
- 長いランキング・詳細ページの中間
- ページ末尾付近
避ける:
- ヒーロー直下を広告で埋める
- 検索・比較UIの操作を阻害する位置
- グラフや表の誤クリックを誘う近接配置
- 財務未取得等の薄いページへの過剰配置

## 5. CMP / 同意管理
EEA・英国・スイス等の要件に対応するため、Google認定CMPを利用する。
GoogleのCMPを使う場合は、有料の外部CMPを必須としない。
選択肢は「同意する / オプションを管理 / 同意しない」の3系統を基本とする。
日本向けページでもプライバシーポリシーから広告・Cookieの扱いを確認できる状態を維持する。

## 6. 広告対象ページの考え方
優先候補は、利用者の滞在時間と情報量が十分なページ。
例:
- 上場企業詳細
- 上場企業業種比較
- 雇用・賃金
- 経済・物価
- エネルギー
- 公共調達詳細・集計

広告を出すことだけを目的に内容を水増ししない。
`noindex` 対象の財務未取得企業等は、広告配信の優先対象にしない。

## 7. パフォーマンス
AdSense導入後は、広告コード追加前後で以下を比較する。
- E2EのJSエラー
- レイアウト崩れ
- CLS相当の目視変化
- モバイル縦長化
- Cloudflare配信負荷
- FunctionsのCPU/リクエスト状況
広告追加で主要UIが不安定になる場合は配置を減らす。

## 8. 収益化後の判断
AdSense収益だけでなく、ページ別PV、検索流入、滞在傾向を合わせて改善対象を決める。
広告クリックを誘導する文言・配置は行わない。
将来別の収益化を追加する場合も、データの中立性とランキング結果を広告主都合で変更しない。
