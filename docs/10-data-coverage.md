## 次の調査・改善の順番

1. 不動産取引の2005Q3以降を収録済み。賃金も2001年以降を各年の公表値として追加済み。今後は2020年方式の遡及再集計系列を別途照合し、比較可能性を改善する。
2. 人口移動は都道府県の長期系列と、市区町村の系列を区別して棚卸しする。合併・境界変更を無視してつながない。
3. 調達は「古い年が存在する」ことと「全提供元がその年をカバーする」ことを分け、提供元×年別件数を確認して不足を選ぶ。2021〜2023年を一律に未収録と扱わない。
4. 住宅統計の682自治体分の差は公表対象制約を含む。取得漏れと公式非公表を区別し、推測補完しない。
5. 34ソースの収集成功とは別に、企業一覧の対象日と定期収集のタイミング、各統計の公表日を確認する。収集成功日だけで「最新」と判断しない。
6. ソースによって収集結果へ対象年月が未記録。公開JSONに保持された原典の対象期間をcollectorのmetricsにも記録し、横断レポートの未記録を減らす。

運用状態は `npm run report:update-status -- --check`。本番の現内容は `verify-production.py` によるハッシュ照合、値と粒度は各専用監査で確認する。
