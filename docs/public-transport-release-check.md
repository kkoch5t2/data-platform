## 本番環境で残る検証

UbuntuのDesktop Commander端末がオフラインのため、既存運用データとCloudflare公開環境にはアクセスできない。本番デプロイは実施していない。

このGitチェックアウトには既存の調達DB・生成JSONがない。全体データ監査は `audit-procurement-awards.py` の `no such table: procurements` で停止。HTML全体監査は想定ページ数不足と既存の調達リンク9件に失敗し、公共交通の失敗はない。既存の定期更新テスト9件は8件成功、孤児プロセス停止の1件が実行環境のプロセス終了待ちタイムアウトとなった。関連する新規JSON・marker公開テストは成功。

端末復帰後、通常の隔離worktree運用でこの変更を適用し、既存データ込みの `release:check`、PC/モバイルE2E、通常のCloudflareデプロイ、release manifest全件照合と本番 `e2e:public-transport` を行う。運用データを欠いたこのdistを本番へ直接アップロードしない。
